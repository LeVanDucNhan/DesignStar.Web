Cài đặt nhanh

  1. Tải DesignStar_Server_v1.0.0.zip.
  2. Giải nén ZIP.
  3. Nhấp phải install\Install.bat và chọn Run as administrator.
  4. Chạy install\CheckEnv.bat.
  5. Nếu không có dòng [FAIL], máy đã sẵn sàng.

AutoCAD BEAM

  • Plugin chính cho command BEAM: runtime\AutoCAD\CivilSoft.BeamAcad.CS.dll.
  • CivilSoft.BeamAcad.VB.dll được đóng kèm cho nhóm command VB phụ.
  • Test NETLOAD/BEAM cuối cùng vẫn cần máy có AutoCAD thật.

Kết nối ChatGPT Actions

  1. Cài StarDesign và chạy Local API tại http://localhost:5289.
  2. Chạy script run_all_build_api_cloudflare.bat trong publish kit để lấy URL tunnel.
  3. Trong GPT Builder, import Actions từ URL dạng https://*.trycloudflare.com/openapi.yaml.
  4. Dùng privacy policy từ endpoint /privacy.
